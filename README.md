# Flipkart UI Clone 🛒

A static frontend clone of the Flipkart e-commerce platform interface, built entirely with vanilla HTML and CSS. This project focuses on replicating the complex desktop layout, typography, and visual hierarchy of India's leading digital marketplace.

> **⚠️ Known Limitation:** This project is currently a **desktop-only** build. It has been developed for larger screens and is not yet responsive for mobile or tablet viewports.

## 🚀 Tech Stack

*   **HTML5:** Semantic markup for structured content delivery.
*   **CSS3:** Custom styling, Flexbox/Grid layouts, and CSS variables for consistent theming.

## ✨ Features

*   **Accurate UI Replication:** Matches Flipkart's primary color scheme, typography, and spacing.
*   **Navigation Bar:** Intricate header design featuring search bars, dropdowns, and cart icons.
*   **Product Grids:** Structured layout for product categories and promotional banners.
*   **Hover States:** Interactive CSS transitions on buttons and product cards to mimic real user interactions.
